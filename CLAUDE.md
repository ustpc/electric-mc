# Claude instructions

Read and follow [AGENTS.md](AGENTS.md). Above all, real data from Manuscript Central never goes in this repository.

Never violate the Chrome Web Store program policies, above all the Manifest V3 rule against remotely hosted code: every script, WebAssembly file and model ships in the package, and `npm run check:remote-code` must pass on the store build before any submission. See "Chrome Web Store policies are never broken" in AGENTS.md.
